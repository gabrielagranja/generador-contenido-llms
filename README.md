# LLM Content Generation MVP

A portfolio project exploring and validating an LLM-assisted social-content workflow for a network of 20+ small businesses.

## Project status

The project is in **discovery and validation**. Research will define the MVP before implementation, combining marketing research, lightweight UX/UI, development and evaluation.

## Users under validation

- **Primary user:** A digital content manager/copywriter managing social communication across a network of 20+ small businesses.
- **Potential secondary user:** Small-business owners or staff with limited social-media confidence. Their need for direct use will be validated before being included in the MVP.

## Product hypothesis

A guided workflow with reusable business context could help the content manager turn a lightweight brief into editable, channel-specific social copy. The potential value is the workflow, context management and human review around generation. This must be tested against general AI tools and current workarounds.

The Project is the planning space. The repository holds the project evidence: documentation, research, design, implementation, testing and presentation materials. Once a task is ready to execute, it will be created as a repository Issue, labelled, assigned to a milestone and added to the Project.
