# Glossary

- Issue: GitHub record for planned work and acceptance context.
- Roadmap: ordered plan-level objectives and phases.
- OpenSpec change: approved contract for one implementable change.
- Delta spec: ADDED, MODIFIED or REMOVED behavioral requirements for a change.
- EARS: requirement style using explicit keywords such as SHALL, MUST and SHOULD.
- BDD scenario: GIVEN / WHEN / THEN acceptance scenario.
- RAG: retrieval-augmented generation over approved business context.
- Human approval: explicit decision that authorizes implementation or Instagram publication.
- Source of truth: canonical document for a particular information type; linked documents must not silently override it.
- Pending: unresolved and blocked until a human decision is recorded.
